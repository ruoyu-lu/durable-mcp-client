# Dependency review

Runtime dependencies are installed separately by npm; their own license and copyright notices remain with each package. No dependency source is bundled in this tarball.

The September 27, 2026 lockfile review covers Ajv 8.20.0, ajv-formats 3.0.1, fast-deep-equal 3.1.3, fast-uri 3.1.8, json-schema-traverse 1.0.0 and require-from-string 2.0.2. All declare MIT except fast-uri, which declares BSD-3-Clause. Transitive versions may vary within dependency ranges on a fresh install; review the installed dependency tree when publishing.
